LongStoryGoes

Simple concepts. Indefinite possibilities.

LongStoryGoes is an evolving story language where English and Python work together.

English tells what the story means.

Python expresses what happens.

sam.push(daniel).hard()
daniel.step_back().quickly()
teacher.enter(classroom)


The same file can be read as a story by a human and understood as actions by a machine.

There is no need to describe the same action twice.

anna.push(leo)


is already the sentence.

Stories first

LongStoryGoes does not try to define every possible concept in advance.

A story can introduce a new idea when it needs one.

If that idea becomes useful across several stories, the underlying concept can evolve and become reusable.

If it is only useful once, it can remain part of that story.

The language therefore grows through use:

story
  ↓
new possibility
  ↓
concept
  ↓
more stories
  ↓
evolution

One story, many possibilities

A story can remain independent of how it is eventually presented.

The same concepts may later be interpreted as:

text and narration
interactive worlds
simulations
AI-readable scenarios
primitive 3D scenes
Blender scenes
other future systems

The story does not need to become more complicated for these possibilities to exist.

The principle

LongStoryGoes keeps the story simple and lets the concepts underneath it grow only when necessary.

English + Python
       ↓
     Story
       ↓
   Concepts
       ↓
   Events / World
       ↓
  Any interpretation


The goal is not to build a complicated language.

The goal is to see how far simple concepts can go.
